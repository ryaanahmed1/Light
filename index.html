Set up your light & NFC tag
  1. On iPhone, open Home → + → Add Accessory. Scan your Tapo L535E’s Matter code and choose a room. Test the bulb in Home.
  2. Open Shortcuts → + → Add Action. Search for Control Home, select your home and bulb, and set its power to on. Name the shortcut . Run it once to test.
  3. Duplicate it for off and name it . For color, duplicate it again, set power on, choose the color in the Home action, and name it . Repeat for other colors you want. Names here update when you select a different light or preset.
  4. Edit the shortcut your NFC tag already runs. Add Open URLs with this dashboard’s web address. Bookmark the same address in Safari and use Safari as your default browser so shortcut results return to the same saved progress.

Each successful shortcut return adds one to the count, including a repeat command. The bulb’s physical state is visible in Apple Home.
